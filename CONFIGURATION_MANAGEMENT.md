# Управление конфигурациями

## Принципы
1.  **Infrastructure as Code (IaC):** Все окружения (dev, staging, prod) описываются в коде (Terraform).
2.  **Конфигурация приложения:** Отделяется от кода. Хранится в иерархических конфигурационных файлах (напр. для разных окружений).
3.  **Секреты:** Никогда не хранятся в коде или VCS. Используется специализированный менеджер секретов (HashiCorp Vault, AWS Secrets Manager). В CI/CD переменные передаются через secure variables.

## Структура хранения
*   `infra/` - Код Terraform для provisioning.
*   `k8s/manifests/` - Kubernetes манифесты (Helm charts).
*   `app/config/` - Конфигурационные файлы приложения (`config-dev.yaml`, `config-prod.yaml`).

*   Секреты (базы данных, API-ключи) - только в менеджере секретов.
